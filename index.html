Blogs (Infraestructura y Bases de Datos)

Blog 1: Configuración de Servidor Linux y Base de Datos

  • 1. Descripción: Configuración de un servidor virtualizado en Ubuntu Server para gestión segura de bases de datos.
  • 2. Requerimientos del cliente: Entorno aislado accesible por SSH con alta disponibilidad para respaldos.
  • 3. ¿Cómo se diseñó la solución?: Uso de Oracle VM VirtualBox con adaptador puente e IP estática.
  • 4. ¿Cómo se implementó la solución?: Instalación de Ubuntu Server, configuración de llaves OpenSSH y motor de base de datos con usuarios privilegiados.
  • 5. ¿Cuál fue el resultado?: Un servidor funcional en red local con respuestas óptimas y acceso remoto verificado.

Blog 2: API RESTful en Flask con SQLite

  • 1. Descripción: Desarrollo de servicio web para control de inventarios con persistencia relacional.
  • 2. Requerimientos del cliente: Operaciones CRUD mediante endpoints HTTP consumibles por aplicaciones externas.
  • 3. ¿Cómo se diseñó la solución?: Arquitectura de backend ligera con Python (Flask) y SQLite.
  • 4. ¿Cómo se implementó la solución?: Creación de rutas HTTP, manejo de excepciones y serialización JSON.
  • 5. ¿Cuál fue el resultado?: API rápida y robusta lista para pruebas de integración y consumo cliente.
