Blogs

Blog 1: Diseño e Implementación de Topología de Red Multinivel en Cisco Packet Tracer

  • 1. Descripción: Simulación y configuración integral de una red corporativa segmentada con subredes VLAN, switches multicapa y enrutamiento estático/dinámico.
  • 2. Requerimientos del cliente: Aislar el tráfico departamental (Administración, Ventas y TI), garantizar conectividad inter-VLAN y configurar servicios DHCP y servidores web simulados.
  • 3. ¿Cómo se diseñó la solución?: Se esquematizó una arquitectura jerárquica de tres capas (Núcleo, Distribución y Acceso), calculando tablas de direccionamiento IPv4 mediante VLSM para optimizar el uso de direcciones IP.
  • 4. ¿Cómo se implementó la solución?: Se configuraron los switches con puertos trunk y access, se habilitó el encapsulamiento 802.1Q en un router mediante subinterfaces (Router-on-a-Stick) y se establecieron protocolos de enrutamiento.
  • 5. ¿Cuál fue el resultado?: Una red robusta, escalable y con comunicación fluida y segura verificada a través de pruebas de paquetes ICMP (ping) exitosas entre subredes independientes.

Blog 2: Configuración de Servidor Linux y Base de Datos en Ubuntu Server

  • 1. Descripción: Configuración de un entorno de servidor virtualizado para gestionar bases de datos relacionales con acceso remoto seguro.
  • 2. Requerimientos del cliente: Un entorno aislado en Linux accesible mediante OpenSSH que alojara un gestor de base de datos eficiente para inventarios.
  • 3. ¿Cómo se diseñó la solución?: Máquina virtual en Oracle VM VirtualBox con adaptador puente (Bridge) para IP estática y reglas estrictas de firewall.
  • 4. ¿Cómo se implementó la solución?: Instalación de Ubuntu Server, configuración de SSH con claves criptográficas y despliegue del motor gestor de base de datos con usuarios y privilegios restringidos.
  • 5. ¿Cuál fue el resultado?: Un servidor funcional listo para producción escolar, con tiempos de respuesta óptimos y conectividad remota validada.

Blog 3: Desarrollo de API RESTful en Python Flask con SQLite

  • 1. Descripción: Desarrollo de servicio web tipo API REST para control de inventarios con persistencia relacional.
  • 2. Requerimientos del cliente: Operaciones CRUD (Crear, Leer, Actualizar, Eliminar) mediante endpoints HTTP accesibles por aplicaciones externas.
  • 3. ¿Cómo se diseñó la solución?: Arquitectura de backend ligera con Python utilizando el microframework Flask y SQLite.
  • 4. ¿Cómo se implementó la solución?: Creación de rutas HTTP, manejo de excepciones, validación de parámetros y serialización JSON.
  • 5. ¿Cuál fue el resultado?: API rápida y robusta lista para pruebas con Postman y consumo desde aplicaciones cliente.
